Sou desenvolvedor full stack, formado em Sistemas de Informação pela UGB. Gosto de pegar um problema de verdade e entregar o sistema funcionando, do banco de dados até a tela.

Meu projeto principal é o **Central de Crédito**, feito sob medida para uma loja que vende a prazo, com nota de risco e cobrança automática pelo WhatsApp. Em todos os meus repositórios, o CodeQL e o Gitleaks rodam a cada push e o Dependabot cuida das dependências.

<a href="https://github.com/Kauesouzavr/Central-credito"><img src="assets/Central-credito.svg" alt="Central de Crédito" width="100%"/></a>

**Central de Crédito**<br/>
Sistema de vendas a prazo feito sob medida para uma loja real. Dá uma nota de risco de inadimplência para cada comprador, monta a fila de cobrança do dia, prevê o caixa das próximas semanas e manda os lembretes pelo WhatsApp sozinho. Tem 98 testes automatizados.<br/>

**Bot Financeiro no WhatsApp**<br/>
Você manda "gastei 45 no ifood" e o bot registra, separa por categoria e responde com o saldo do mês. A regra de negócio não depende do WhatsApp e é toda testada, e o webhook confere a assinatura de cada mensagem.<br/>
